# Reckon SEO Autopilot: AI-native SEO operations

Reckon SEO Autopilot is an AI-native, multi-tenant SEO operations platform from Reckon Technologies Ltd. Its core idea is a governed agent: it turns evidence from your website into traceable recommendations and, only with authorization, into verified actions. It sits alongside the SEO tools in [ReckonERP](https://app.reckon.tech) as part of Reckon's AI direction.

## Detailed features

### Verified-site crawling and audits
- Register a website and prove control with a DNS TXT challenge before anything is crawled
- Respectful crawling: robots.txt is enforced, only public hosts are fetched, and daily crawl budgets apply per organization
- Homepage and bounded same-host page discovery with sitemap analysis
- Source-linked findings with impact, confidence, effort, recommendation and verification steps

### Audit coverage
- Titles, meta descriptions, headings, canonical links, noindex signals and image alt text
- Mobile, social, structured data, duplicate content and AI-crawler access checks
- Keyword, content, ecommerce, enterprise, media and query audits, plus GEO (AI search) checks from crawl evidence
- Scheduled daily or weekly crawls

### AI that is governed
- A read-only technical audit prioritizer with typed, validated output
- An approval-gated AI fix-drafting agent
- SEO action proposals that go through approval, execution, verification and rollback
- Bring your own OpenAI or Anthropic key per organization, with encrypted storage and visible token usage

### Teams, security and tenancy
- Organizations with owner, admin, editor and viewer roles and approval-bound role changes
- Email invitations, MFA with recovery codes, session management and account recovery
- Tenant isolation enforced in the database
- Audit events and request IDs for traceability

### Dashboard and integrations
- Responsive React dashboard with crawl history and evidence
- Read-only MCP tool discovery for tenants
- CMS discovery with WordPress support, where writes require approval

### Responsible by design
- No fake reviews, cloaking, hidden text or scaled low-value content
- Crawled text is treated as untrusted

## Technology

Reckon SEO Autopilot is an independent platform built with Python, FastAPI, PostgreSQL, Redis and a React and TypeScript dashboard, rather than on Frappe.

## Who it is for

Businesses, agencies and in-house teams that want technical SEO checked continuously, with every AI suggestion backed by evidence and approved by a person.
